ALOK BORANA - HTML & CSS PORTFOLIO STARTER

Files:
- index.html: website structure and content
- style.css: design, layout, hover effects, and responsive rules

HOW TO RUN:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in Chrome, or use Live Server.
4. Replace your.email@example.com and the sample LinkedIn/GitHub links.
5. Confirm project descriptions and technologies match what you actually built.
6. Take desktop and mobile screenshots for internship submission.

This project uses HTML and CSS only. The Google Fonts import needs internet; system fallback fonts will work offline.
